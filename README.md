 
# ✦ Picksy — Trendy Accessories & Beauty Store

Picksy is a modern, responsive e-commerce Single Page Application built with React.js and Supabase. It is designed as a stylish online shopping experience focused on trendy accessories, beauty essentials, and skincare products.

The project combines a soft-luxe visual style with smooth animations, responsive layouts, product management, authentication, and cart functionality.

## ✨ Features

- 🛍️ Browse trendy products
- 💄 Accessories, Beauty & Skincare categories
- 🔎 Product filtering by category
- 🛒 Add products to cart
- ➕ Update product quantities
- 🗑️ Remove products from cart
- 💰 Automatic cart total calculation
- 🔐 User authentication with Supabase
- 👤 Login / Logout functionality
- 🧑‍💼 Admin Product Portal
- ➕ Admin can add new products
- 🗑️ Admin can delete products
- 🖼️ Product image support
- 📱 Fully responsive design
- ✨ Animated hero section and marquee
- 🎨 Soft Luxe, Feminine & Premium UI
- 🔔 Toast notifications for cart actions
- 📦 Supabase database integration

## 🧑‍💼 Admin Portal
 

Picksy includes an Admin Portal for product management.

The Admin Portal is **only accessible after the user has logged in**. Once authenticated, the Admin Portal can be accessed from the navigation bar.


Admin functionality includes:

* Add product name
* Select product category
* Set product price
* Add product image
* Add product description
* View current products
* Delete products
